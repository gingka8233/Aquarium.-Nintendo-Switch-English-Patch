# Aquarium. - Nintendo Switch English Translation Patch

An English localization project for the Nintendo Switch version of **Aquarium**. The project adapts the existing English PC dialogue to the Switch scripts and localizes menus and interface assets.

> **Disclaimer:** This is an unofficial fan project. It is not affiliated with, endorsed by, or associated with Nintendo, ENTERGRAM or any right holder.

## ✨ Features

- English dialogue based on the existing PC English script.
- English interface assets.
- English subtitles for the opening video.

## 🎮 Installation

You will need:

- A legally obtained copy of *Aquarium.*.
- A compatible Nintendo Switch modding environment or emulator with game mod support.

### Installation Steps

1. Download the latest patch from the [Releases](https://github.com/gingka8233/Aquarium.-Nintendo-Switch-English-Patch/releases) section.
2. Extract the archive.
4. Place the replacement files in the 0100D11018A7E000 directory in Atmosphere or Emulator directory.
5. Launch the game.

**Important:** The exact installation path depends on your environment.

I've tested the patch on both emulator and original hardware, both are functional.

## 🐛 Bug Reports

If you encounter an issue, please open a GitHub issue and include:

- The affected screen or character.
- A screenshot showing the problem.
- The patch version.
- Whether you are using original hardware or an emulator.
- A short description of the issue.

Reports of clipped text, untranslated Japanese content, and incorrect character names are especially helpful.
